## 1. Executive Summary

### Goals
Transform the X4 Trading System from a single-page arbitrage calculator into a **comprehensive trading and economic analysis platform** with:
- Multi-page navigation architecture
- Multiple data perspectives (sectors, wares, assets, analytics)
- Advanced features from X4SaveGameAnalysis.R
- Full coverage of game data documented in x4research/

### Key Improvements
- ✅ Multi-page UI with dedicated views
- ✅ Resource area tracking (mining)
- ✅ Economy log analysis (trade history)
- ✅ Fleet management (hierarchies)
- ✅ NPC crew management
- ✅ Station production tracking
- ✅ Advanced analytics and visualizations

### 2.2 Current Limitations ❌

1. **Single Page Design** - All functionality on one page
2. **No Resource Areas** - Mining data not tracked
3. **No Economy Log** - No trade history analysis
4. **No Fleet Management** - Commander/subordinate links not parsed
5. **Basic Station Info** - Missing modules, crew, production data
6. **Basic Ship Info** - Missing equipment, cargo details
7. **No NPC Management** - Crew skills not tracked
8. **No Discovery State** - Can't filter undiscovered objects
9. **No Analytics** - No market analysis or trends

## 3. Documentation Insights

### 3.1 From x4research/*.md

#### **BasicInfo.md**
- **Discovery State**: `knownto="player"` attribute for filtering
- **Faction Colors**: Palette for visualization
- **Player Profile**: `/savegame/player` with `@name`, `@money`, `@location`

#### **EconomyInfo.md**
```xml
Path: /savegame/economylog/entries[@type='trade']/log
Attributes:
  - time: game-time stamp (seconds)
  - ware: ware id
  - buyer/seller: component ids
  - price: centi-credits (divide by 100)
  - v: quantity traded
  - b/bmax: buyer cargo fill/capacity
  - s/smax: seller cargo fill/capacity
```

#### **ResourceInfo.md**
```xml
Path: /savegame/universe//component[@class='sector']/resourceareas/resourcearea
Attributes:
  - macro: resource region id
  - ware: ore/silicon/ice/methane
  - max: maximum yield
  - time: recharge time
Recharge rate: max / time
```

#### **StationInfo.md**
```xml
Construction: ./construction/sequence/entry[@index]
Personnel: ./control/post[@component=npc_id]
Workforce: ./workforces/workforce[@race, @amount]
Source: <source entry="faction_ware" nameindex="1"/>
```

#### **ShipInfo.md**
```xml
Size: ship_s/ship_m/ship_l/ship_xl
Pilot: ./control/post[@id='aipilot']/@component
Fleet: ./connections/connection[@name='commander']/@ref
Equipment: weapons, shields, engines
Cargo: storage component with ware[@amount, @volume]
```

#### **NPCInfo.md**
```xml
Path: /savegame/universe//component[@class='npc' and @owner='player']
Skills: ./traits/skill[@type, @value] or ./traits/skills
Values: 0-10 scale (UI stars = value/2)
Roles: aipilot, engineer, manager, shiptrader
```

#### **SectorInfo.md**
```
Attributes: code, owner, knownto, contested, macro
Ownership: faction id (argon, teladi, player)
```

### 3.2 Data Model Summary

```
Universe Hierarchy:
└── Sectors
    ├── Stations
    │   ├── Modules (construction sequence)
    │   ├── Crew (NPCs in posts)
    │   ├── Workforce (per-race counts)
    │   └── Trade Offers
    ├── Ships
    │   ├── Pilot (NPC)
    │   ├── Commander (fleet link)
    │   ├── Subordinates
    │   ├── Equipment (weapons, shields, etc)
    │   └── Cargo
    ├── Resource Areas
    │   └── Recharge rates per ware
    └── Discovery State (knownto)

Economy Log:
└── Trade Entries
    ├── Timestamp
    ├── Buyer/Seller
    ├── Price & Quantity
    └── Cargo states

NPCs:
└── Skills (0-10)
└── Roles (pilot, engineer, manager)
```

## 4. R Script Analysis

### 4.1 Key Features from X4SaveGameAnalysis.R

The R script (1668 lines) provides extensive analytics:

#### **Data Extraction**
1. **Sector Info** (line 372)
   - Coordinates, ownership, contested status
   - Resource areas with recharge rates
   - Cluster/sector hierarchy

2. **Player Owned Objects** (line 418)
   - Ships and stations
   - Spawn times
   - Sector locations

3. **Fleet Hierarchies** (line 423)
   - Commander/subordinate connections
   - Fleet wings structure

4. **NPCs** (line 439)
   - Skills: piloting, engineering, boarding, management, morale
   - Roles: pilot (ship), engineer (ship/station), manager, shiptrader

5. **Stations** (line 482)
   - Managers, engineers, shiptraders
   - Workforce by race
   - Module count
   - Hull/mass calculation: `hull = modules × 250,000`, `mass = hull / 300`

6. **Ships** (line 528)
   - Size (XS/S/M/L/XL/XXL)
   - Model matching from CSV
   - Pilot info with skills
   - Crew assignments

7. **Trade Log** (cached per GUID)
   - Buy/sell history
   - Price tracking
   - Volume analysis

8. **Sales/Buys** (line 693-742)
   - Station sales
   - Ship resupplies
   - Buyer/seller tracking

9. **Destroyed Objects** (line 744)
   - Destruction log
   - Killers tracking

10. **Account Transfers** (line 758)
    - Station manager surplus transfers
    - Money flow tracking

11. **Pirates/Police** (line 784-805)
    - Harassment events
    - Police interdictions
    - Response tracking

#### **Visualizations Generated**
1. **Sector Map** (line 816)
   - Plotly interactive map
   - Color-coded by faction
   - Position calculations
   - Discovery filter (spoilers.hide)

2. **Bar/Area Plots** (line 1022)
   - Time-series analysis
   - Resource production
   - Economic trends

3. **Sunburst Plots** (line 1227)
   - Hierarchical data visualization
   - Fleet structures
   - Station compositions

4. **HTML Tables** (line 1521)
   - DT data tables
   - Sortable, filterable
   - Export functionality

#### **Cache Strategy**
```r
cache_resources_{GUID}.csv.gz   - Resource areas (per save)
cache_log_{GUID}.csv.gz         - Log entries (cumulative)
cache_tradelog_{GUID}.csv.gz    - Trade history (cumulative)
```

### 4.2 Lessons for Rust Implementation

1. **Per-GUID Caching**: Cache trade logs per save game GUID
2. **Cumulative Logs**: Merge old cached logs with new entries
3. **Resource Extraction**: Only extract once, cache aggressively
4. **Fleet Parsing**: Complex XPath queries for hierarchies
5. **Skill Aggregation**: Handle both `skill` nodes and `skills` attribute
6. **Time-based Filtering**: Use game time for history windows
7. **Faction Color Mapping**: Centralized palette
8. **Spoiler Handling**: Filter by `knownto` attribute

// router.jsx
const { useState, useEffect } = React;

const routes = {
  '/': DashboardPage,
  '/trade-routes': TradeRoutesPage,
  '/sectors': SectorsPage,
  '/sectors/:code': SectorDetailPage,
  '/wares': WaresPage,
  '/wares/:id': WareDetailPage,
  '/assets': AssetsPage,
  '/analytics': AnalyticsPage,
  '/npcs': NPCsPage,
  '/settings': SettingsPage,
};

function Router() {
  const [currentPath, setCurrentPath] = useState(window.location.pathname);

  useEffect(() => {
    const handlePopState = () => setCurrentPath(window.location.pathname);
    window.addEventListener('popstate', handlePopState);
    return () => window.removeEventListener('popstate', handlePopState);
  }, []);

  function navigate(path) {
    window.history.pushState({}, '', path);
    setCurrentPath(path);
  }

  // Match route (with params)
  const matchRoute = () => {
    for (const [pattern, Component] of Object.entries(routes)) {
      const paramNames = [];
      const regex = new RegExp(
        '^' + pattern.replace(/:(\w+)/g, (_, param) => {
          paramNames.push(param);
          return '([^/]+)';
        }) + '$'
      );
      const match = currentPath.match(regex);
      if (match) {
        const params = {};
        paramNames.forEach((name, i) => params[name] = match[i + 1]);
        return { Component, params };
      }
    }
    return { Component: NotFoundPage, params: {} };
  };

  const { Component, params } = matchRoute();

  return (
    <RouterContext.Provider value={{ navigate, currentPath, params }}>
      <Component />
    </RouterContext.Provider>
  );
}

const RouterContext = React.createContext();
function useRouter() { return React.useContext(RouterContext); }

window.Router = { Router, useRouter };

// src/parsers/resources_xml.rs
use anyhow::Result;
use quick_xml::{events::Event, Reader};
use std::collections::HashMap;
use crate::models::{ResourceArea, SectorResources};

pub fn extract_resource_areas(
    xml_content: &str,
    sectors: &[crate::models::Sector],
) -> Result<Vec<SectorResources>> {
    let mut reader = Reader::from_str(xml_content);
    reader.trim_text(true);

    let mut sector_resources: HashMap<String, Vec<ResourceArea>> = HashMap::new();
    let mut buf = Vec::new();

    // Track current sector
    let mut current_sector: Option<String> = None;

    loop {
        match reader.read_event_into(&mut buf) {
            Ok(Event::Start(ref e)) => {
                match e.name().as_ref() {
                    b"component" => {
                        let mut is_sector = false;
                        let mut code = None;

                        for attr in e.attributes() {
                            if let Ok(attr) = attr {
                                match attr.key.as_ref() {
                                    b"class" if attr.value.as_ref() == b"sector" => is_sector = true,
                                    b"code" => code = Some(String::from_utf8_lossy(&attr.value).to_string()),
                                    _ => {}
                                }
                            }
                        }

                        if is_sector {
                            current_sector = code;
                        }
                    }
                    b"resourcearea" => {
                        if let Some(ref sector_code) = current_sector {
                            let mut macro = None;
                            let mut ware = None;
                            let mut max = None;
                            let mut time = None;

                            for attr in e.attributes() {
                                if let Ok(attr) = attr {
                                    let key = attr.key.as_ref();
                                    let value = String::from_utf8_lossy(&attr.value).to_string();

                                    match key {
                                        b"macro" => macro = Some(value),
                                        b"ware" => ware = Some(value),
                                        b"max" => max = value.parse().ok(),
                                        b"time" => time = value.parse().ok(),
                                        _ => {}
                                    }
                                }
                            }

                            if let (Some(m), Some(w), Some(max_val), Some(time_val)) =
                                (macro, ware, max, time)
                            {
                                let recharge_rate = if time_val > 0 {
                                    max_val as f64 / time_val as f64
                                } else {
                                    0.0
                                };

                                let sector_name = sectors
                                    .iter()
                                    .find(|s| s.code == *sector_code)
                                    .map(|s| s.name.clone())
                                    .unwrap_or_else(|| sector_code.clone());

                                sector_resources
                                    .entry(sector_code.clone())
                                    .or_insert_with(Vec::new)
                                    .push(ResourceArea {
                                        sector_code: sector_code.clone(),
                                        sector_name,
                                        macro: m,
                                        ware: w,
                                        max: max_val,
                                        time: time_val,
                                        recharge_rate,
                                    });
                            }
                        }
                    }
                    _ => {}
                }
            }
            Ok(Event::End(ref e)) => {
                if e.name().as_ref() == b"component" {
                    current_sector = None;
                }
            }
            Ok(Event::Eof) => break,
            Err(e) => return Err(anyhow::anyhow!("XML parse error: {}", e)),
            _ => {}
        }
        buf.clear();
    }

    // Aggregate by ware per sector
    let mut results = Vec::new();
    for (sector_code, resources) in sector_resources {
        let mut total_recharge: HashMap<String, f64> = HashMap::new();
        for res in &resources {
            *total_recharge.entry(res.ware.clone()).or_insert(0.0) += res.recharge_rate;
        }

        results.push(SectorResources {
            sector_code,
            resources,
            total_recharge,
        });
    }

    Ok(results)
}

                        let mut value = None;

                        for attr in e.attributes() {
                            if let Ok(attr) = attr {
                                match attr.key.as_ref() {

                    current_npc_id = None;
                }

pub fn assign_npc_roles(
    npcs: &mut [NPC],
    xml_content: &str,
) -> Result<()> {
    let mut reader = Reader::from_str(xml_content);
    reader.trim_text(true);

    let mut buf = Vec::new();
    let mut post_assignments: Vec<(String, String, String)> = Vec::new(); // (npc_id, role, assignment_id)

    // First pass: collect all control/post assignments
    let mut current_component_id: Option<String> = None;

    loop {
        match reader.read_event_into(&mut buf) {
            Ok(Event::Start(ref e)) | Ok(Event::Empty(ref e)) => {
                match e.name().as_ref() {
                    b"component" => {
                        for attr in e.attributes().flatten() {
                            if attr.key.as_ref() == b"id" {
                                current_component_id = Some(String::from_utf8_lossy(&attr.value).to_string());
                            }
                        }
                    }
                    b"post" => {
                        let mut post_id = None;
                        let mut npc_id = None;

                        for attr in e.attributes() {
                            if let Ok(attr) = attr {
                                match attr.key.as_ref() {
                                    b"id" => post_id = Some(String::from_utf8_lossy(&attr.value).to_string()),
                                    b"component" => npc_id = Some(String::from_utf8_lossy(&attr.value).to_string()),
                                    _ => {}
                                }
                            }
                        }

                        if let (Some(pid), Some(nid), Some(ref cid)) = (post_id, npc_id, &current_component_id) {
                            post_assignments.push((nid, pid, cid.clone()));
                        }
                    }
                    _ => {}
                }
            }
            Ok(Event::Eof) => break,
            _ => {}
        }
        buf.clear();
    }

    // Second pass: assign roles to NPCs
    for (npc_id, post_id, assignment_id) in post_assignments {
        if let Some(npc) = npcs.iter_mut().find(|n| n.id == npc_id) {
            npc.assignment_id = Some(assignment_id);
            npc.role = Some(match post_id.as_str() {
                "aipilot" | "pilot" => NPCRole::PilotShip,
                "engineer" => {
                    // Determine ship vs station by assignment type
                    // Would need additional context, default to ship
                    NPCRole::EngineerShip
                }
                "manager" => NPCRole::ManagerStation,
                "shiptrader" => NPCRole::ShipTrader,
                _ => NPCRole::Unassigned,
            });
        }
    }

    Ok(())
}

### 6.4 Cache Strategy

#### **Per-GUID Caching**
```rust
// src/services/cache.rs (additions)

#[derive(Serialize, Deserialize)]
pub struct EconomyLogCache {
    pub game_guid: String,
    pub entries: Vec<TradeLogEntry>,
    pub last_save_time: i64,
}

impl EconomyLogCache {
    pub fn load(game_guid: &str) -> Result<Self> {
        let path = format!("cache_tradelog_{}.json.gz", game_guid);
        if !Path::new(&path).exists() {
            return Ok(Self {
                game_guid: game_guid.to_string(),
                entries: Vec::new(),
                last_save_time: 0,
            });
        }

        let file = File::open(&path)?;
        let decoder = GzDecoder::new(file);
        let cache: Self = serde_json::from_reader(decoder)?;
        Ok(cache)
    }

    pub fn save(&self) -> Result<()> {
        let path = format!("cache_tradelog_{}.json.gz", self.game_guid);
        let file = File::create(&path)?;
        let encoder = GzEncoder::new(file, Compression::default());
        serde_json::to_writer(encoder, self)?;
        Ok(())
    }

    pub fn merge_new_entries(&mut self, new_entries: Vec<TradeLogEntry>, save_time: i64) {
        // Only add entries newer than last save time
        for entry in new_entries {
            if entry.time > self.last_save_time {
                self.entries.push(entry);
            }
        }

        self.last_save_time = save_time;

        // Sort by time
        self.entries.sort_by_key(|e| e.time);
    }
}
```
